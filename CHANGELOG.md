# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-07-09

- Introduced AI Skill Specification (AISS) v1.0.
- Added AI Professional Communication Skills (APCS) v1.0 as the first reference implementation.
- Added workplace communication examples across Slack, email, Jira, GitHub PRs, standups, incidents, technical discussions, code reviews, architecture discussions, and 1:1 conversations.
- Added reference implementations for code review, architecture review, incident response, mentoring, and technical writing.
- Added contribution, governance, compatibility, architecture, scoring, roadmap, and adoption documentation.
- Added dependency-free documentation validation and GitHub Actions CI.
