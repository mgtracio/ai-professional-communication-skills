# Security Policy

This repository contains documentation and specification files. It does not currently ship runtime software that processes secrets or user data.

## Reporting Issues

If you find a security concern in examples, workflows, or guidance, open a private report through GitHub security advisories when available, or contact the maintainer directly.

## Sensitive Data In Examples

Examples must not include real credentials, customer data, private identifiers, incident details, or personal information. Use synthetic names and realistic but fictional technical context.
