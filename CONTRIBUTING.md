# Contributing

Thanks for helping improve AISS and its reference implementations.

## Contribution Principles

- Prefer model-agnostic guidance over tool-specific instructions.
- Keep skills human-readable and easy to review.
- Add examples when changing behavior.
- Use precise workplace language instead of motivational filler.
- Avoid presenting AISS as an industry standard; it is an open specification introduced by this project.

## Ways To Contribute

- Improve the AISS specification.
- Add or refine communication examples.
- Add reference implementations that follow `spec/aiss/v1.0/schema.md`.
- Improve scoring dimensions and anti-pattern detection.
- Clarify documentation.

## Pull Request Checklist

- The change is scoped and easy to review.
- New skills include `SKILL.md`, principles, workflow, output format, and examples.
- New examples include context, input, review, and improved output.
- `npm test` passes.
