# Incident Response Skill

Version: 1.0.0  
AISS: 1.0  
Purpose: Produce accurate, calm, and actionable incident communication.

## Workflow

1. Lead with impact and current status.
2. Distinguish facts from assumptions.
3. Name owner and next update time.
4. Avoid blame.
5. Keep customer-facing and internal language separate.

## Output

```text
Incident Update
Impact:
Status:
Known Facts:
Unknowns:
Owner:
Next Update:
```
