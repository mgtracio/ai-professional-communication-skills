# Code Review Skill

Version: 1.0.0  
AISS: 1.0  
Purpose: Produce clear, actionable, respectful code review feedback.

## Workflow

1. Identify the behavior being reviewed.
2. Separate correctness risks from style preferences.
3. Explain impact.
4. Suggest the smallest useful change.
5. Mark blockers clearly.

## Output

```text
Code Review
Status: APPROVE | COMMENT | REQUEST_CHANGES
Findings:
Questions:
Suggested Changes:
```
