# APCS Anti-patterns

- Passive aggression
- Defensive framing
- Over-apologizing
- Unclear ownership
- Blame without evidence
- Emotionally loaded wording
- Unnecessary verbosity
- Ambiguity
- Weak or hidden request
- Demanding tone
- Excessive confidence
- Lack of confidence
- Missing context
- No action requested
- Incomplete technical explanation
- Invented certainty
- Audience mismatch
