# APCS Output Format

```text
Communication Review
Status: PASS | NEEDS_REVISION | BLOCKED

Dimensions:
- Professionalism: 1-5
- Clarity: 1-5
- Respectfulness: 1-5
- Collaboration: 1-5
- Conciseness: 1-5
- Confidence: 1-5
- Actionability: 1-5
- Technical Accuracy: 1-5

Context:
Risks:
Suggestions:
Improved Version:
```

## Status Rules

Use `PASS` when the message is ready for the stated context.

Use `NEEDS_REVISION` when the message has fixable issues.

Use `BLOCKED` when the message lacks facts required for a responsible rewrite.
