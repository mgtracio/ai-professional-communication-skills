# APCS Patterns

## Request Pattern

```text
Context
Objective
Action requested
Deadline or priority
Closing
```

## Status Update Pattern

```text
Current state
Progress
Blockers
Next steps
Owner
Next update
```

## Review Comment Pattern

```text
Observation
Risk
Suggested change
Reason
Tone check
```

## Incident Update Pattern

```text
Impact
Current status
Known facts
Unknowns
Owner
Next update time
```
