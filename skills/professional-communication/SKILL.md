# AI Professional Communication Skills

Version: 1.0.0  
AISS: 1.0  
Purpose: Review, improve, and standardize professional workplace communication.

## Use When

- reviewing a message before sending
- improving Slack, email, Jira, PR, incident, or standup communication
- adapting a message for a specific audience
- making a technical message clearer and more actionable

## Do Not Use When

- the user needs legal, medical, or financial advice
- the message requires facts that are not provided
- the request asks for manipulation, harassment, or deception

## Primary Output

The primary output is a `Communication Review` followed by an optional improved version.

## Core Rule

Improve the communication without changing the facts.
