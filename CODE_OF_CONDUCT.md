# Code of Conduct

This project is built around respectful, professional communication. Contributors are expected to model that standard.

## Expected Behavior

- Be clear, kind, and constructive.
- Critique ideas and artifacts, not people.
- Assume good intent while still being precise about risks.
- Make requests actionable.
- Avoid sarcasm, harassment, insults, and exclusionary language.

## Unacceptable Behavior

- Personal attacks or discriminatory language.
- Public shaming.
- Sustained disruption of project discussions.
- Publishing private information without permission.

## Enforcement

Maintainers may edit, hide, or remove contributions that violate this code of conduct. Serious or repeated violations may result in blocked participation.
