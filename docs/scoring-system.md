# Scoring System

APCS uses a five-level score for each dimension.

| Score | Meaning |
| --- | --- |
| 5 | Excellent; ready to send with no material changes. |
| 4 | Strong; minor improvements possible. |
| 3 | Acceptable; useful but needs revision. |
| 2 | Risky; likely to cause confusion or friction. |
| 1 | Poor; should not be sent in its current form. |

## Dimensions

- Professionalism
- Clarity
- Respectfulness
- Collaboration
- Conciseness
- Confidence
- Actionability
- Technical Accuracy

## Status

- `PASS`: all material dimensions are strong enough for the context.
- `NEEDS_REVISION`: the message can be fixed with edits.
- `BLOCKED`: the message lacks required facts or has unresolved risk.
