# Compatibility

AISS is designed to be model-agnostic.

## Compatible Surfaces

- ChatGPT
- Codex
- Claude
- Cursor
- Kiro
- local assistants
- internal company assistants

## Compatibility Requirements

A compatible assistant should be able to:

- read Markdown instructions
- follow structured output formats
- preserve user-provided facts
- distinguish review from rewrite
- avoid inventing missing context

## Non-goals

AISS does not require a specific runtime, plugin system, vector store, or execution engine.
