# Glossary

## AISS

AI Skill Specification. An open, model-agnostic approach introduced by this project for defining reusable AI capabilities.

## APCS

AI Professional Communication Skills. The professional communication reference implementation of AISS.

## Skill

A portable AI capability described through principles, workflow, inputs, outputs, examples, and review criteria.

## Dimension

A measurable quality used to evaluate skill output.

## Pattern

A reusable structure for creating consistent outputs.

## Anti-pattern

A recurring failure mode the skill should detect and correct.

## Reference Implementation

A concrete skill that demonstrates how to apply AISS.
