# Design Principles

## Model Agnostic

Skills should work across modern AI assistants. Avoid instructions that depend on one vendor, model family, or interface.

## Human Readable

Every skill should be understandable as documentation. If humans cannot review it, teams cannot trust it.

## Portable

Skills should be usable outside this repository without hidden dependencies.

## Composable

Skills should define boundaries clearly enough to combine with other skills.

## Reviewable

Outputs should have stable formats and measurable dimensions.

## Grounded

The assistant should preserve facts, uncertainty, ownership, and constraints. It should improve communication without inventing information.
