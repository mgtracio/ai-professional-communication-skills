# Adoption Guide

## Individual Use

Copy the relevant skill into your assistant context and ask for a review or rewrite.

## Team Use

Agree on the dimensions that matter most for your team. Keep examples close to your real workflows, but remove sensitive information.

## Repository Use

Store adapted skills in version control. Review skill changes like code changes.

## Enterprise Use

Treat AISS skills as policy-adjacent artifacts. Legal, security, and support teams may need different anti-patterns and output constraints.
