# AISS Versioning

AISS uses semantic versioning.

## Patch

Patch changes clarify language, fix examples, or improve wording without changing expected behavior.

## Minor

Minor changes add optional fields, new examples, or new reference implementations while keeping existing behavior valid.

## Major

Major changes alter required skill structure, output contracts, or compatibility expectations.

## Skill Versioning

Individual skills may evolve independently, but each skill should declare which AISS version it follows.
