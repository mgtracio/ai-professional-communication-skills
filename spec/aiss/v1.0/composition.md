# Skill Composition

AISS skills can compose when their boundaries are clear.

## Composition Rules

- Preserve each skill's output contract.
- Resolve conflicts explicitly.
- Prefer the stricter safety or accuracy constraint.
- Do not merge unrelated dimensions without naming the tradeoff.

## Example

APCS can compose with the incident response skill:

- Incident Response provides operational structure.
- APCS reviews tone, clarity, and actionability.

The combined output should still identify facts, uncertainty, owner, impact, and next update time.
